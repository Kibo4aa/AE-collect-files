COLLECT FILES PLUS - untuk After Effects
=========================================
https://github.com/Kibo4aa/AE-collect-files

Mengumpulkan footage, font, dan file plugin yang benar-benar dipakai
project After Effects ke satu folder, langsung dari file .aep
(After Effects tidak perlu dibuka).

CARA PAKAI
1. Jalankan CollectFilesPlus.exe (Mac: CollectFilesPlus.app).
2. Pilih file .aep, atau drag file .aep ke jendela aplikasi
   (bisa juga ke ikon CollectFilesPlus.exe).
3. Tab "1. Comp & opsi": centang comp utama yang dipakai.
   Precomp di dalamnya ikut dibaca otomatis.
4. Klik Analisa, lalu cek tab Plugin / Font / Footage.
   Hapus centang file plugin yang tidak ingin dicopy.
5. Pilih folder tujuan, lalu klik Collect.
   Di folder hasil ada laporan (_report.txt) yang menjelaskan cara
   memakai hasilnya di komputer lain.

BANYAK PROJECT SEKALIGUS (BATCH)
- Drag beberapa file .aep (atau folder berisi .aep) ke jendela aplikasi
  atau ke ikon CollectFilesPlus.exe. Semuanya masuk ke tab
  "Batch (banyak project)". Klik "Collect semua project".
- Bisa langsung dari Explorer: di tab Batch klik
  "Pasang di menu klik kanan Send to". Setelah itu pilih file .aep,
  klik kanan > Send to > Collect Files Plus
  (Windows 11: klik "Show more options" dulu).
- Semua hasil masuk ke Folder tujuan yang sama; tiap project ke folder
  <nama>_Collected sendiri. Ringkasannya ada di file
  CollectFilesPlus_batch_....txt di folder tujuan.
- Satu project gagal tidak menghentikan project lain.
- Versi command line: collect-files-plus.exe collect a.aep b.aep -o D:\Hasil

CATATAN
- Windows SmartScreen: klik "More info" lalu "Run anyway"
  (exe belum punya code signing).
- File .aep asli tidak pernah diubah. Kalau project hasil disimpan
  ulang, salinan aslinya ada di folder (Backup).
- Copy file plugin tidak ikut memindahkan lisensinya. Plugin berbayar
  tetap butuh installer dan aktivasi resmi di komputer tujuan.
- Adobe Fonts tidak dicopy; aktifkan lagi lewat Creative Cloud.
- Versi command line: collect-files-plus.exe --help
- Script versi After Effects (JSX) ada di folder jsx:
  File > Scripts > Run Script File... (aktifkan dulu "Allow Scripts to
  Write Files and Access Network" di Preferences > Scripting & Expressions).

ENGLISH
Collects footage, fonts and only the plugin files your After Effects
project actually uses, straight from the .aep. Run CollectFilesPlus.exe,
pick the .aep, tick the main comps, click Analisa (Analyze), then Collect.
Copying plugin files does not transfer their licenses.
